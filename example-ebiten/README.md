# Ebiten

A minimal Ebiten Pong game on Wavedash, compiled to WebAssembly.

[See it live](https://wavedash.com/playtest/ebiten-example/314fe89c-26ab-4e41-b40a-cdb83e872a3f)

## Prerequisites

- [Go](https://go.dev/dl/)
- [Wavedash CLI](https://github.com/wvdsh/cli/releases)

## Quick start

Replace `game_id` in [`wavedash.toml`](./wavedash.toml) with your Wavedash game ID, then:

```
./build.sh
wavedash dev
```
